# Templates

This directory holds canonical SKILL.md templates for each skill class.

- `operation.SKILL.template.md` is the template for operation-class skills.
- `delegated.SKILL.template.md` is the template for delegated-class skills.
- `inline.SKILL.template.md` is the template for inline-class skills.
- `orchestrated.SKILL.template.md` is the template for orchestrated-class skills.
- `planning.SKILL.template.md` is the template for planning-class skills.
- `documentation.SKILL.template.md` is the template for documentation-class skills.

Use these templates as canonical skeletons when creating new skill directories in CREATE mode.

Do not edit these templates directly.
Copy them into a new skill directory.
Adapt the copy.
