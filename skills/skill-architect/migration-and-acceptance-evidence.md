# Migration and Acceptance Evidence

## Purpose

Index the evidence posture and acceptance gates for the approved family architecture
without converting those gates into execution authority.

## Applicability

Applies to ownership-ledger context, future migration decisions, metadata and
Markdown conformance evidence, and passive-contract review of this scope.

## Non-goals

This document does not migrate inventory, run validators or lint, create evidence,
approve policy, authorize tools, make writes, delegate, or declare completion.

## Authority source

The authority is the local [taxonomy and ownership map](taxonomy-and-ownership-map.md)
and [class boundary rules](class-boundary-rules.md), particularly their ownership and
passive-contract boundaries. Acceptance context remains descriptive and local to this
workspace.

## Scope

Acceptance context includes preserving the five classes, assigning one canonical
owner per outcome, publishing this six-concern passive scope, preserving passive
workflow handoffs, reconciling aliases consistently, and reporting available
structural, editorial, and contract evidence. The ownership ledger precedes any
move or rewrite. Unsupported runtime loader enforcement and automated selector
scoring remain explicitly out of scope rather than unverified completion claims.

## Evidence status

The architecture is approved and the ledger is preserved as rollback evidence. The
listed gates remain acceptance criteria; validator and lint results are reported by
the consuming operation, not established by this passive document.

## Shared passive-contract verification

This concern is coupled to the indexed scope and contains reference context only.
It grants no execution authority, implicit loading, tool use, file change, delegation,
or completion authority.
