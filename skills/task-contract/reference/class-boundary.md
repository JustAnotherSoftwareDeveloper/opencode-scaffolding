# Class Boundary

This workspace is a `documentation`-class passive reference with a `reference` role.

## Passive Scope

The content describes shared task semantics.

It does not provide executable steps, tools, writes, delegation, assignment authority,
or completion claims.

A consuming workflow retains responsibility for its own procedures, outputs, and
verification.

## Non-Transitive Loading

Loading this documentation does not automatically read every referenced file.

Further reference is explicit rather than a recursive or transitive authority chain.

This store cannot add imperative steps, authorize another skill, transfer ownership
of effects, or count as completion evidence for a consuming workflow.

## Neighboring Class Boundaries

The proposal workflow retains its `operation` class and its own source-grounded
procedure.

The decomposition and plan workflows retain their own workflow procedures and
structural interfaces.

This documentation owner does not change those classes, select their skills, or
merge their responsibilities.
