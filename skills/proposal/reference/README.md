# Proposal Reference

- [proposal-format.md](./proposal-format.md) is the authoring entry point for
  per-section decision content, proportionality, plain Markdown, navigation, and
  evidence presentation.
- [writing-style.md](./writing-style.md) defines observable readability,
  scanability, evidence-language, and verb-choice standards.
- [workspace-contract.md](./workspace-contract.md) defines workspace structure,
  source preservation, metadata, evidence labels, and completed-document rules.
- [implementation-format.md](./implementation-format.md) defines concrete
  implementation-change grouping, headings, concise bullets, and optional detail.
- [section-rationale.md](./section-rationale.md) explains the decision and
  requirements-engineering rationale independent of a fixed layout.
- [../examples/README.md](../examples/README.md) indexes short, standard, complex,
  and implementation workspaces for raw-Markdown validation.
