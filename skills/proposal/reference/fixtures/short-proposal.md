# Adopt sentence-case proposal headings

## Summary

Use sentence-case headings in generated proposals. This improves plain-text
scanning without changing decision content ([format rules](../proposal-format.md)).

## Problem and context

Title-case compound headings add visual noise in raw Markdown and do not add
decision information ([format rules](../proposal-format.md)).

## Scope

- In scope: proposal headings generated by the proposal skill
  ([format rules](../proposal-format.md)).
- Out of scope: changing other skill formats without dependency evidence
  ([format rules](../proposal-format.md)).

## Options and recommendation

- Keep title case: retain the readability issue
  ([format rules](../proposal-format.md)).
- Use sentence case: recommended because it preserves hierarchy with less visual
  noise ([format rules](../proposal-format.md)).

## Requirements

- Proposal headings use sentence case ([format rules](../proposal-format.md)).

## Acceptance criteria

- A generated short proposal has sentence-case headings and no table of contents
  ([format rules](../proposal-format.md)).

## Decision record

- **Decision:** Use sentence case for generated proposal headings
  ([format rules](../proposal-format.md)).
- **Open decisions:** None.
