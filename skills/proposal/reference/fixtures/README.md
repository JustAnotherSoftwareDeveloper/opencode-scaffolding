# Proposal Format Fixtures

Use these fixtures to inspect generated Markdown as raw text and rendered
Markdown. They demonstrate the contract; they are not additional templates.

- [Short proposal](./short-proposal.md): isolates complete decision content
  without a table of contents, empty optional sections, or decorative syntax.
- [Standard proposal](./standard-proposal.md): demonstrates distinct requirements
  and acceptance criteria, inline evidence links, one source index, and a linked
  implementation overview.
- [Complex proposal](./complex-proposal.md): demonstrates a justified table of
  contents, expanded migration and risk detail, and unchanged evidence and source
  index rules.
- [Implementation overview](./implementation-overview.md): demonstrates multiple
  named changes in one affected area plus a separate area, linked to the standard
  proposal recommendation.

Check each fixture for sentence-case headings, ordinary paragraphs and lists,
applicable optional content only, descriptive relative evidence links, one
supporting-sources index, and no authoring instructions or unresolved
placeholders.
