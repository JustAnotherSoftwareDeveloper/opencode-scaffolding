# Delegation Model

## Analyst Lane Selection Rationale

Justify selected exploration/analysis lanes based on the lane requirement matrix in proposal workflow documentation. Each lane's selection should be grounded in evidence needs for the proposed changes, following the unified deep-proposal approach to comprehensive discovery.

## Delegated Analysis Summary

Summarize tradeoffs, risks, contradictions, framework-fit assessment, and decision impact from analysis lanes. This synthesis informs acceptance criteria regardless of initial discovery scope assumptions.
