# Proposal Skill Resources

This directory contains the proposal skill and its local supporting resources.

- `SKILL.md`: The workflow instructions loaded by agents.
- `templates/`: Reusable proposal artifact skeletons.
- `docs/`: Supplemental proposal-skill reference docs.

Keep workflow-critical instructions in `SKILL.md`. Use `templates/` for copyable artifact formats and `docs/` for supporting reference material that should not replace the loaded skill workflow.
