# Schemas

This directory is a placeholder for skill-specific class-contract schemas.
When a new skill directory is created, a copy of the canonical example
should be placed here and adapted to that skill's contract.

Canonical class-contract references live in `skills/skill-architect/class-taxonomy.md`.
Per-skill schemas (e.g., `skills/breakdown-tasks/schema/task-packet.schema.json`) are the
current pattern for schema management.

Use these examples as reference and seeding material when creating new skill
directories. Do not edit the canonical files; copy them here and adapt to
each skill's contract.
