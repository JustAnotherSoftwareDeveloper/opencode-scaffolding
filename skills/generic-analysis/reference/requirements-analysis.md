# Requirements Analysis

## Elicit Requirements

- Identify the business objective, users, stakeholders, and intended outcomes.
- Capture functional, non-functional, regulatory, operational, and interface requirements.
- Separate needs, constraints, assumptions, preferences, and proposed solutions.
- Record each requirement with a source and rationale.

## Validate Requirements

- Check requirements for clarity, consistency, completeness, feasibility, and testability.
- Identify conflicts, duplications, dependencies, and ambiguous terms.
- Define acceptance criteria and observable verification methods.
- Resolve material conflicts with the responsible decision authority.

## Prioritize Delivery

- Rank requirements by value, risk, urgency, dependency, and implementation effort.
- Define the minimum viable set that achieves the stated objective.
- Trace each requirement to design, implementation, and verification artifacts.
- Control changes through explicit impact assessment and approval.
