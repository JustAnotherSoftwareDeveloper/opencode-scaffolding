# Failure Mode Analysis

## Identify Failure Modes

- Define the system, process, component, or operation under review.
- Enumerate ways each element can fail to meet its intended function.
- Identify causes, local effects, system effects, and existing controls for each failure mode.
- Include human, process, dependency, configuration, and environmental failure paths.

## Assess Severity

- Rate severity, occurrence, detectability, and affected scope using defined scales.
- Identify failure modes with unacceptable safety, security, compliance, or availability consequences.
- Test whether controls prevent the failure, detect it promptly, or only reduce harm.
- Prioritize failure modes using the agreed risk method.

## Reduce Exposure

- Define design, process, monitoring, or recovery changes for priority failure modes.
- Assign an owner, deadline, verification method, and acceptance criterion to each action.
- Reassess ratings after implementing controls.
- Maintain the analysis as the system, process, or operating context changes.
