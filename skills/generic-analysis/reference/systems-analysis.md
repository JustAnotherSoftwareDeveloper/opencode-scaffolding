# Systems Analysis

## Map The System

- Define the system boundary, purpose, inputs, outputs, and external actors.
- Identify components, dependencies, interfaces, resources, and control points.
- Trace the flow of information, work, material, money, or authority through the system.
- Mark constraints, single points of failure, and unowned interfaces.

## Analyze Dynamics

- Identify feedback loops, delays, accumulations, and threshold effects.
- Test how local optimization changes system-level outcomes.
- Trace likely second-order effects from proposed interventions.
- Identify bottlenecks and dependencies that constrain throughput or reliability.

## Select Interventions

- Target leverage points that improve the stated system objective.
- Compare interventions by effect, cost, delay, reversibility, and unintended consequences.
- Define signals that verify the expected system response.
- Monitor for shifted burdens and new bottlenecks after intervention.
