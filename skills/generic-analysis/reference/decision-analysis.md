# Decision Analysis

## Define The Decision

- Name the decision owner, deadline, and authority boundary.
- List feasible options, including maintaining the current state.
- Remove options that violate fixed constraints before comparing the remaining options.
- Set criteria that reflect the stated objective.

## Compare Options

- Gather evidence for each option's benefits, costs, risks, and dependencies.
- Weight criteria only when stakeholders have established their relative importance.
- Compare options on reversibility, time to value, implementation effort, and downside exposure.
- Test the leading option against its strongest competitor.

## Recommend An Action

- Select the option that satisfies the weighted criteria and constraints.
- State material trade-offs and the conditions that would change the recommendation.
- Define the first reversible action and the evidence needed before commitment.
- Record the decision rationale for later review.
