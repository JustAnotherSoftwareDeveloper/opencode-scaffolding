# Decision Analysis

## Define The Decision

- State the decision owner, decision deadline, and authority boundary.
- Enumerate feasible options, including maintaining the current state.
- Exclude options that violate fixed constraints before comparison.
- Define decision criteria that reflect the stated objective.

## Compare Options

- Gather evidence for each option's benefits, costs, risks, and dependencies.
- Weight criteria only when stakeholders establish relative importance.
- Evaluate reversibility, time to value, implementation effort, and downside exposure.
- Test the preferred option against the strongest competing option.

## Recommend An Action

- Select the option that satisfies the weighted criteria and constraints.
- State material trade-offs and the conditions that would change the recommendation.
- Define the first reversible action and the evidence needed before commitment.
- Record the decision rationale for later review.
