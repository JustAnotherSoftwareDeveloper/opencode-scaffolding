# Gap Analysis

## Define States

- Describe the current state using observable capabilities, outcomes, and measures.
- Define the target state, deadline, and acceptance criteria.
- Establish a shared baseline before comparing states.
- Separate confirmed facts from assumptions about either state.

## Identify Gaps

- Compare current and target capabilities, processes, resources, controls, and outcomes.
- State each gap as a measurable difference from the target state.
- Trace each gap to its likely causes, dependencies, and affected scope.
- Rank gaps by impact on the target outcome and urgency.

## Plan Closure

- Define actions that close each priority gap.
- Assign owners, dependencies, measures, and completion conditions.
- Identify residual gaps that require an explicit acceptance decision.
- Reassess progress against the target state at defined checkpoints.
