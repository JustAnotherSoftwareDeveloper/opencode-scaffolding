# Comparative Analysis

## Define The Comparison

- State the alternatives or artifacts under comparison and the decision they inform.
- Define consistent scope, baseline conditions, and evaluation criteria.
- Exclude alternatives that violate non-negotiable constraints.
- Gather equivalent evidence for each remaining alternative.

## Evaluate Criteria

- Compare capabilities, quality, cost, risk, complexity, maintainability, and fit for purpose.
- Distinguish measured differences from subjective preferences.
- Weight criteria only when decision owners establish relative importance.
- Identify material trade-offs, dependencies, and conditions unique to each alternative.

## Reach A Conclusion

- Identify the leading alternative for the stated criteria and constraints.
- State circumstances under which another alternative becomes preferable.
- Document evidence gaps that limit confidence in the comparison.
- Recommend a validation step when the leading alternatives remain close.
