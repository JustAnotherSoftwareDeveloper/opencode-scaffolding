# Scenario Analysis

## Define The Focal Decision

- State the decision, planning horizon, and outcomes that require preparation.
- Identify driving uncertainties that materially affect those outcomes.
- Separate controllable variables from external uncertainties.
- Define indicators that reveal which conditions are emerging.

## Construct Scenarios

- Build a limited set of plausible, internally consistent future conditions.
- Vary critical uncertainties rather than creating minor variations of one forecast.
- Describe the assumptions, triggers, opportunities, and risks for each scenario.
- Avoid assigning certainty to a single scenario.

## Test Responses

- Test the current plan against each scenario.
- Identify robust actions that perform acceptably across multiple scenarios.
- Define contingent actions linked to observable indicators.
- Record the conditions that require changing course.
