# Root Cause Analysis

## Establish The Outcome

- Describe the observed failure, deviation, or unexpected result.
- Define the expected behavior and the measurable gap from that behavior.
- Construct a timeline from the earliest relevant condition through detection.
- Preserve direct observations separately from retrospective explanations.

## Trace Causal Paths

- Identify immediate mechanisms that produced the outcome.
- Trace each mechanism to enabling conditions, decisions, and system controls.
- Test each proposed cause against timing, evidence, and counterfactual behavior.
- Distinguish root causes from contributing factors, triggers, and symptoms.

## Form Corrective Actions

- Target controls at validated causal mechanisms.
- Prefer actions that prevent recurrence over actions that only detect recurrence.
- Assign an owner, verification signal, and completion condition to each action.
- Reassess residual risk after applying the proposed controls.
