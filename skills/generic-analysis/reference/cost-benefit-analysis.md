# Cost-Benefit Analysis

## Define The Baseline

- State the decision, alternatives, time horizon, and affected stakeholders.
- Define the baseline cost and benefit of maintaining the current state.
- Identify monetary and material non-monetary consequences.
- Separate one-time costs from recurring costs and benefits.

## Estimate Value

- Estimate implementation, operating, maintenance, transition, and opportunity costs.
- Estimate expected benefits, avoided losses, and time to realization.
- State assumptions, discounting rules, and uncertainty ranges for material estimates.
- Avoid assigning false precision to sparse or indirect evidence.

## Compare Alternatives

- Compare net value, payback period, downside exposure, and distribution of effects.
- Test the conclusion against high-impact uncertainty and alternative assumptions.
- State benefits or harms that resist monetary valuation.
- Select the option that satisfies the objective within accepted cost and risk limits.
