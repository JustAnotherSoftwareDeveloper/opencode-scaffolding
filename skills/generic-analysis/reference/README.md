## Apply Evidence Rules

- Separate direct observations from reported facts, assumptions, interpretations, and recommendations.
- Prefer primary sources over summaries when source access exists.
- Record the source, date, scope, and reliability limits for material evidence.
- Seek disconfirming evidence for the leading hypothesis.
- Avoid treating correlation, sequence, or consensus as proof of causation.
- Mark conclusions as low confidence when evidence lacks relevance, reliability, or sufficiency.

## Calibrate Conclusions

- Use high confidence only when multiple reliable sources support the conclusion and credible alternatives fail.
- Use moderate confidence when available evidence supports the conclusion but material gaps or assumptions remain.
- Use low confidence when evidence is sparse, indirect, conflicting, or unverified.
- State the condition that would strengthen, weaken, or reverse the conclusion.

## Prioritize Next Actions

- Prioritize actions by decision impact, urgency, reversibility, cost, and risk reduction.
- Request the smallest additional fact that can resolve a material uncertainty.
- Recommend reversible actions when uncertainty remains high.
- Escalate when authority, safety, compliance, privacy, or irreversible impact exceeds the stated scope.
