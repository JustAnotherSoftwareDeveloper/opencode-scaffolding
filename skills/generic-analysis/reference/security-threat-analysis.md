# Security Threat Analysis

## Define The Security Context

- Identify assets, trust boundaries, users, privileges, data classifications, and exposure points.
- Define the system scope, intended behavior, and security objectives.
- Map data flows, interfaces, dependencies, and administrative control paths.
- Record assumptions about identity, authorization, isolation, and external services.

## Identify Threats

- Identify threat actors, capabilities, motivations, and likely attack paths.
- Trace how each attack path reaches assets across trust boundaries.
- Assess vulnerabilities, control gaps, exploitability, and potential impact.
- Include threats to confidentiality, integrity, availability, privacy, and accountability.

## Select Controls

- Prioritize threats by likelihood, impact, exposure, and control maturity.
- Define preventive, detective, corrective, and recovery controls for material threats.
- Verify controls through targeted tests, monitoring, and incident response exercises.
- State residual exposure and acceptance authority for unmitigated risk.
