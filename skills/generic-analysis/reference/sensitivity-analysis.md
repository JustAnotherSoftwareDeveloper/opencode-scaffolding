# Sensitivity Analysis

## Define The Model

- State the conclusion, forecast, or decision metric under examination.
- Identify input variables, assumptions, and fixed constraints.
- Establish baseline values and the source for each material input.
- Isolate variables that materially influence the output.

## Vary Inputs

- Vary one material input at a time across a plausible range.
- Test combined changes when inputs interact or correlate.
- Record resulting changes to the conclusion, ranking, or decision threshold.
- Identify breakpoints where the preferred conclusion changes.

## Report Robustness

- Rank inputs by their influence on the result.
- State assumptions that require validation before commitment.
- Prefer actions that remain effective across material input ranges.
- Define monitoring signals for high-sensitivity variables.
