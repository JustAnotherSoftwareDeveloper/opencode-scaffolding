# Planning Pipeline Workflow References

- [Analysis Only](./analysis-only.md) ends with an evidence-calibrated assessment; it creates no decision or plan workspace.
- [Proposal Only](./proposal-only.md) records a decision from explicit source documents without additional analysis or task planning.
- [Plan Only](./plan-only.md) creates an executable plan from explicit source documents, with no proposal-derived audit by default.
- [Analysis To Proposal](./analysis-to-proposal.md) turns a persisted assessment into an evidence-backed decision workspace.
- [Analysis To Plan](./analysis-to-plan.md) turns a persisted assessment into an executable plan without a decision workspace.
- [Proposal To Plan](./proposal-to-plan.md) requires proposal authorization before planning and enters audit pending when the proposal-derived plan is published.
- [Analysis To Proposal To Plan](./analysis-to-proposal-to-plan.md) covers the full path from assessment through authorized decision and plan to proposal-derived audit handoffs.
- [Proposal-Derived Audit Lifecycle](./proposal-derived-audit-lifecycle.md) defines audit, bounded-fix, revised-plan, and mandatory re-audit handoffs for proposal-derived plans.
