# Validation Checklist

Verify every authored or migrated skill before publication.

## Metadata

- Confirm `name` matches the directory.
- Confirm `description` uses the class-specific trigger prefix.
- Confirm `class` is valid.
- Confirm `selection.role` and grouped tags are present and request-facing.
- Confirm `aliases`, `use_when`, `not_for`, and `supports` are concise and valid.

## Direct Selection Review

- Confirm every tag and condition is grounded, discriminative, atomic, stable,
  discoverable, non-redundant, and scoped.
- Confirm the profile is the smallest sufficient evidence set.
- Confirm aliases preserve the same canonical concept.
- Evaluate owner, neighbor, unrelated, paraphrased, and low-overlap requests.

## Documentation Hygiene

- Search related documentation for obsolete count, popularity, implementation, and metadata-shape instructions.
- Confirm all related documents name the same required metadata and validation behavior.
